# 아이디어 (ideas/)

구체화되지 않은 구상의 보관. plans/ 로 갈 만큼 무르익지 않은 것을 버리지 않고 담아두는 자리.

## 규칙

- 파일명: `kebab-topic.md` (날짜 접두 없음 — 아이디어는 주제 중심)
- 구체화되어 작업 단위가 잡히면 `plans/<date>-<topic>/` 로 승격 + 이 폴더 파일은 "→ plans/... 로 이동" 마커만 남기거나 삭제
- 아이디어가 **기각**되면 파일 상단에 `# 기각 (2026-04-XX)` 섹션 + 사유를 추가하고 보존 (왜 안 했는지 추적)
